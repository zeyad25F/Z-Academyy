# Z-Academy Website

Static website (HTML/CSS/JS). No build tools needed.

## 1. Edit your details
Open `js/config.js` and replace the phone, WhatsApp, email, social links and your Google Form link. Every page updates automatically.

## 2. Host free on GitHub Pages
1. Create a GitHub account and a new repository (e.g. `z-academy`).
2. Upload all files from this folder (keep the folder structure).
3. Go to Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / root → Save.
4. Your site goes live at `https://YOUR-USERNAME.github.io/z-academy/`.

Custom domain: Settings → Pages → Custom domain.
Other free hosts: Netlify or Cloudflare Pages (drag and drop this folder).
